# PrimePack – Java Desktop Version

This repository contains the **JavaFX desktop version** of **PrimePack**, a **multi-platform application** . 

PrimePack is designed for **veterinary clinics**, focusing on **animal health management**.

**Platforms:**
- Desktop: Java / JavaFX  
- Web: PHP / Symfony  
- Mobile: Codename One  

This repository includes **only the Java desktop implementation**.
